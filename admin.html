Cara Publish

Pilih salah satu. Semua perubahan disimpan di perangkat ini sampai Anda publish.

🚀 A. Langsung Online (GitHub Pages)

Paling praktis — bisa dari HP. Sekali setup, setelah itu tinggal upload ZIP lalu tekan Publish. Website otomatis update ±1 menit.

Token hanya disimpan di browser perangkat ini, tidak ikut ter-upload ke website.

💾 B. Simpan ke Folder di PC

Untuk Chrome / Edge di laptop. Pilih folder Velom Car Auto Generate Website, file foto & data langsung ditulis ke sana. Setelah itu upload folder ke hosting.

📦 C. Download Paket Update

Mengunduh ZIP berisi foto baru + data/cars.js. Ekstrak ke folder website (timpa file lama).

🖥 D. Tanpa Browser (GENERATE.bat)

Taruh ZIP di folder INBOX/NamaBrand/ lalu dobel-klik GENERATE.bat. Semua otomatis.
